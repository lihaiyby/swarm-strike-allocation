## 三、三条关键结论

### 结论 1：**冠军换人了**

| 口径 | 冠军 | 亚军 |
|---|---|---|
| v1（固定时刻 + 立即命中） | **自适应遗传** | 影子价格 CBBA |
| **v2 时序（本表）** | **影子价格 CBBA（1.2581）** | **预分配+退火（1.2535）** |
| | 自适应遗传降到**第 3**（1.2216） | |

**原因不是自适应遗传变差了，而是它的"偏科"在时序下被放大**：

- 它的 a 仍是**最高**（r_a = 1.310，歼灭 95/110，突防率最低 23.0%）；
- 但它的 **b 只有 0.27**（r_b = 0.935，**低于贪心基线**）；
- 时序下它做了 **38.6 次决策**（最多），频繁重分配把兵力摊薄，**整团歼灭率上不去**。

而影子价格 CBBA 的 b = 0.47（r_b = 1.670），一项就拉回 0.15 分。

> **时序把"能不能打掉"的问题，变成了"能不能清干净"的问题。**

### 结论 2：突防率 23%~37%，短视最优 67%

| 分组 | 突防率 |
|---|---|
| 最好的（自适应遗传） | **23.0%** |
| 中游（多数算法） | 28~33% |
| 贪心基线 | 35.8% |
| **短视最优** | **67.4%** |

**短视最优的表现最典型**：它只做 **1 次决策**（把全部兵力一次压上），之后无兵可用 →
40 架被歼、**83 架突防**。这印证了 v1 的结论，而且在时序下更极端。

### 结论 3：实时性出现"擦线"现象

| 算法 | 单次平均 | 单次最大 | 判定 |
|---|---|---|---|
| 自适应遗传 | **823 ms** | **1167 ms** | 平均合格（<1 s），**最大超线** |
| 双种群遗传 | 586 ms | **2163 ms** | 平均合格，**最大严重超线** |
| 其余 10 个 | 0.5~6.1 ms | ≤ 128 ms | 全部合格 |

> 时序口径下决策次数从 4~6 次涨到 **30~39 次**，遗传类算法的耗时被放大。
> **若按"单次最大 ≤ 1 秒"判定，两个遗传算法都不合格**；按"单次平均"则合格。
> **这条口径要请老师明确。**

## 五、一个已修复的记账 bug（记录在此）

第一版时序仿真里，战局拉长时敌机会**穿过球心跑到另一侧**，
用"推进后 |pos| ≤ 700"判突防会漏判——实测 **110 架敌机里有 73 架凭空消失**（既不算歼灭也不算突防）。

**修法**：改成**射线与球面求交**（解 $|p+vt|=R$，判断交点是否落在区间内）。
修后 **歼灭 + 突防 = 敌机总数**，逐场景校验通过。
