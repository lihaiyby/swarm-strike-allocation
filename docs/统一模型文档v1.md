## 1. 集合与索引

| 符号 | 含义 |
|---|---|
| $I$ | 我方资源池：当前可用的无人机集合（不含已冻结机） |
| $J$ | 当前在空敌方无人机集合 |
| $K$ | 敌群集合，$K = \text{DBSCAN}(J)$（增量聚类，噪点独立成群） |
| $J_k$ | 敌群 $k$ 内的目标集合，$k \in K$ |
| $I_k$ | 与敌群 $k$ 配对的我方打击编组（群对群一一对应） |

## 2. 参数（来自 config/，禁止硬编码）

| 符号 | 含义 | 取值 |
|---|---|---|
| $R$ | 战场半径 | 3~5 km |
| $T$ | 战局总时长 | $T = R / 50$ s |
| — | 入侵波次 | $t = 0,\ T/3,\ 2T/3$ s，每波 6 群、随机方向 |
| $v_j$ | 敌机 $j$ 的价值 | {10, 5, 2}，比例 2:5:3，按类型定档 |
| $p_j$ | 我方单机对敌机 $j$ 的毁伤概率 | 由机动档映射：机动 10/5/2 → 0.4/0.7/0.9 |
| $q_1, q_2, r$ | 敌机对我方杀伤参数 | 格斗型 $q_1$≈0.2；范围伤害型半径 $r$≈100 m 内 $q_2$≈0.5 |
| $w_k$ | 敌群 $k$ 的威胁度 | 熵权法-TOPSIS（依据：总价值、速度、距基地距离） |
| $P^*$ | 期望毁伤阈值 | 0.9 |

## 3. 决策变量

$$x_{ij} \in \{0,1\}, \quad i \in I,\ j \in J$$

$x_{ij}=1$ 表示我方无人机 $i$ 分配给敌方目标 $j$。每架无人机为自杀式，打击后即退出。

## 4. 目标函数（统一，算法内部可改写收益形式但须导向同一目标）

$$\max_X \ f(X) = \sum_{j \in J} v_j \cdot P_j(X), \qquad P_j(X) = 1 - \bigl(1 - p_j\bigr)^{\sum_{i \in I} x_{ij}}$$

即最大化打击总收益（与评估指标 a 一致）。

## 5. 约束条件

| 编号 | 约束 | 说明 |
|---|---|---|
| C1 | $\sum_{j} x_{ij} \le 1,\ \forall i \in I$ | 单架单目标（自杀式） |
| C2 | $\sum_{i} x_{ij} \ge m_j$ 或 $\sum_i x_{ij}=0$ | 打就必须达到配额下限 $m_j = \lceil \ln(0.1)/\ln(1-p_j) \rceil$（保证 $P_j \ge 0.9$） |
| C3 | $x_{ij}=0,\ \forall i \in I_k,\ j \notin J_k$ | 群对群一一对应（暂定硬约束） |
| C4 | $\sum_{i \in I_k}\sum_{j \in J_k} x_{ij} \ge |J_k|$ | 编组内多打一（我方数量 ≥ 敌群目标数） |
| C5 | $x_{ij}=0$ 对已冻结的 $i$ | 已下达指令的无人机不可改派 |

**不设毁伤上限**（上限即 100%）：$P_j$ 随架数单调趋近 1，达到 0.9 所需架数有限（$p_j$=0.4/0.7/0.9 → $m_j$=5/2/1 架），不存在无解。

## 6. 可行性恢复规则（资源不足时）

1. 敌群按威胁度 $w_k$ 从高到低排序（优先打高价值目标，高威胁自然靠前）；
2. 从高到低依次纳入，累加配额需求 $\sum m_j$；
3. 加入下一群会使总需求超过 $|I|$ 时，放弃该群及其后所有更低威胁群；
4. 保证任意场景均有可行解。

## 7. 惩罚函数【待定形式，初稿建议】

- **超兵力**：分配数超过资源池时，按超出架数线性罚入总评分【系数待定】；
- **求解超时**：单次分配耗时 ≤1 s 不罚，超出部分按超时时长罚入总评分【系数待定】。

## 8. 统一评估指标（算法外部，由 evaluation 模块计算）

| 指标 | 名称 | 定义 |
|---|---|---|
| a | 打击总收益 | $\sum_j v_j \cdot P_j$（期望值口径，不做随机判定） |
| b | 威胁消除率 | 被歼灭群威胁度之和 / 全部敌群威胁度之和；**$P_j \ge 0.9$ 的敌机视为歼灭，群内全部歼灭则该群被歼灭** |
| c | 稳定性 | 各指标在 50 个场景上的标准差 |
| d | 效费比 | a /（我方投入无人机总数 × 单机价值 1） |
| e | 求解效率 | 单次分配平均耗时 |

**总评分** = 50 个场景下五项指标的加权总分，权重【待定】。

**口径说明**：主评估采用期望值口径（确定性、可复现）；蒙特卡洛随机毁伤口径作为鲁棒性附录（可选）。

## 9. 仿真流程（算法不可见的部分）

```
触发（波次 0/T/3/2T/3 s、敌机新增、我方战损）
  → 增量 DBSCAN 分组（旧群保留 ID，噪点独立成群）
  → 熵权 TOPSIS 威胁评估
  → 可行性恢复（必要时放弃低威胁群）
  → 配额计算 + 算法求解（接口调用，计时）
  → 下达指令：X 中非零机冻结、移出资源池
  → 波次结算：毁伤按期望值口径、战损按 q1/q2/r、资源池更新
终止：敌机耗尽 / 资源池耗尽 / 到达 T
```
