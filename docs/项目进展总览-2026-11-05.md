## 1. 项目定位与边界

### 1.1 一句话

面向"敌方多群分散入侵、分波次直奔基地"的想定，建一个**统一仿真与算法比较平台**，把 8 个候选任务分配算法放在同一套规则下比较，并说清楚"谁好、为什么好"。

### 1.2 三个边界（写进方案、全程遵守）

| 边界 | 含义 | 后果 |
|---|---|---|
| **只做分配，不做路径规划** | 算法输出"哪架机打哪个目标"，不模拟怎么飞过去 | 我方无人机全程静止；不建模航程、飞行时间、中途拦截 |
| **不追求新算法** | 算法由外部提供（文献复现），平台负责让它们可比 | 平台的核心价值在"统一"与"诊断"，不在算法本身 |
| **双方都是无人机** | 敌方多类型成编队入侵；我方同质自杀式无人机多打一 | 我方同质是**硬约束**（2026-11-04 明确） |

### 1.3 想定核心参数（已固化）

| 项 | 取值 |
|---|---|
| 战场 | 上半球，R ∈ {3000, 4000, 5000} m，基地在球心 |
| 防线 | 半径 **700 m** 内球面（批注要求 ≥500 m） |
| 战局时长 | **T = R / 50** s（60 / 80 / 100 s） |
| 敌机总量 | n ∈ [100, 150]，三波均分 |
| 波次 | 3 波，t = 0, T/3, 2T/3；每波 **6 团** |
| 团形态 | 高斯扩散 σ = 150~250 m；团心间距 ≥ 4σ；散点占 5%（**各自独立成团**） |
| 我方 | **3n**（可切 2.5n / 2.0n），**同质**，**自杀式**，部署于内球面 |
| 场景库 | **50 个固定种子**（1000~1049） |
| 感知参数 | DBSCAN `eps = 550 m`（k-distance 拐点中位数 553）、`min_samples = 3` |

### 1.4 敌方四类（比例合计 1.00）

| 类型 | 占比 | 价值 | 单机毁伤概率 | 配额 | 对我方杀伤 |
|---|---|---|---|---|---|
| 侦察型 `recon` | 30% | 2 | 0.4 | **5** | 无 |
| 自杀攻击型 `suicide_strike` | 50% | 5 | 0.7 | **2** | 无 |
| 单点格斗型 `fighter` | 13.3% | 10 | 0.7 | **2** | 点杀伤 q=0.2 |
| 范围伤害型 `area_damage` | 6.7% | 10 | 0.9 | **1** | 面杀伤 q=0.5, r=100 m |

**结构性张力**：侦察机仅占 30%、价值最低（2），却要吃 **53%** 的兵力（5 架 ÷ 每目标均值 2.83 架）。这是全部 a/b 冲突的根源。

### 3.2 感知层（`perception/`）

| 工作 | 内容 |
|---|---|
| 增量 DBSCAN | 簇与旧群按**成员重叠数最大**继承编号；只对成簇群生效（散点不继承） |
| 熵权法 | 三特征（群总价值、平均速度、到基地最近距离）自动定权；单群/无区分度时退化为等权 |

### 3.3 统一模型层（`model/`）

| 工作 | 内容 |
|---|---|
| 毁伤公式 | $P_j(k) = 1-(1-p_j)^k$ |
| 配额 | $m_j=\lceil \ln 0.1/\ln(1-p_j)\rceil$ → p=0.4/0.7/0.9 对应 **5/2/1** |
| 目标函数 | $\max \sum_j v_j P_j$ |
| 约束检查 | C1（每机一目标）、C2（0 或 ≥ m_j）、C3（群对群，**未启用**）、C5（冻结机） |
| 可行性恢复 | `select_groups`：按威胁度从高到低纳入，超兵力则跳过（背包式） |
| 评分函数 | `Model.damage` / `Model.quota` / `Model.objective` / `Model.check` |
| **D6 距离衰减** | 新增 `Model.pair_p()`（绝对口径）与 `pair_p_matrix()`（**相对口径**，含硬射程截断）；`config/eval.yaml → range_decay`，**默认关闭，关闭时与旧版逐位一致** |

### 3.4 算法层（`algorithms/`）

**共 5 个算法，全部走统一接口 `solve(state, model) -> X`。**

| 注册名 | 性质 | 说明 |
|---|---|---|
| `greedy` | **基线** | 按威胁度顺序，给每目标派满配额，取离群质心最近的机 |
| `random_feasible` | **下界参照** | 随机排列目标、整包填充；种子由 `(t, 最小敌机 id)` 派生，可复现 |
| `myopic_opt` | **近视最优参照** | 每轮用精确背包把当前**全部剩余兵力**分配掉，不看后续波次 |
| `ga_iap` | **文献复现** | IAP-NSGA-III（刘富樯）；双目标（收益最大 + 出动架数最少）；固定 200 代 |
| `cbba_ye` | **文献复现** | 叶赞改进 CBBA；双向候选池 + K-means 类别奖励 + **槽展开最大权匹配** |

**接口设计**：算法只能读 `state`、只能返回 `X`；毁伤公式、配额、约束、目标函数全部由平台提供，算法内部不允许另写一套。新增算法 = 一个文件 + `@register`，平台自动发现。

### 3.5 评估与统计层（`evaluation/`）

| 文件 | 职责 |
|---|---|
| `b_metric.py` | **b 的唯一实现**：`group_elimination_rate(P, groups, values, threshold) -> (b, num, den)` |
| `oracle.py` | 精确上界：`a_opt`（多选择背包）、`a_kill_opt`（0/1 背包）、`b_opt`（群级背包） |
| `score.py` | 三套总分口径 + 统计检验 + 帕累托 |
| `metrics.py` | 逐轮指标（诊断用） |

**`score.py` 的能力清单**

| 能力 | 说明 |
|---|---|
| 方案 A 相对基准分 | 逐场景"指标 ÷ 基线"，加权求和；基线恒为 1.000；新增算法不改变既有算法分数 |
| 方案 B 不合成 | 指标均值 + 帕累托前沿 + 逐场景胜负矩阵 + Friedman/Nemenyi |
| 方案 C 风险调整 | A 的逐场景比值再做 `mean − λ·std`，λ=0 时等于 A |
| 四种汇聚方式 | `mean` / `median` / `geomean` / `ratio_of_means` |
| 三种时间计分 | `threshold`（默认，达标即满分）/ `ratio` / `rank` |
| 显著性 | 对基线的 Wilcoxon + **Holm 校正**，输出 `p_*` 与 `sig_*`（星号） |
| Nemenyi | `nemenyi_cd(k, N)` 工具函数，k 过大时告警 |
| 帕累托 | 支持任意维度组合，一次给三组平面 |

## 4. 全部修改明细 · 按性质

### 4.1 口径类修正（改了会改变结论）

| # | 问题 | 原设定 | 改后 | 原因 | 量化影响 |
|---|---|---|---|---|---|
| 1 | **b 的群定义** | 动态 DBSCAN 群 | **真值团**（生成时 `cluster`） | 散点每回合领新 ID，分母随算法行为膨胀 | 同场景 greedy 21 个群 ID / ga_iap **53 个** / 真实 21 个 = **2.52 倍** |
| 2 | **b 的权重** | TOPSIS 威胁度 | **价值** | 威胁度每回合在当轮群集合内归一化，跨回合不可加 | — |
| 3 | **b 的计算时机** | 逐回合累加 | **战局结束一次性** | 防重复计数 | — |
| 4 | **主得分项** | `a_gain = Σv_jP_j` | **`a_kill = Σv_j·[P_j≥0.9]`** | 前者按概率加权且计入幸存者部分毁伤，与"敌方损失价值"语义不符 | easy/greedy：589.71 → **647.96**（差 58 分） |
| 5 | **ga_iap 停止准则** | 200 代 或 0.8 s | **固定 200 代** | 墙钟截断使同一态势解不同 | 0.05/0.15/0.40/0.80 s → 11/54/128/200 代 → 出动 50/43/53/55（**±13%**） |
| 6 | **散点数量** | `round(n·ratio)` | 二项抽样 | 恒定值消灭随机性 | 50 场景散点数 2~10 |
| 7 | **两份 b 实现** | `simulate` 与 `metrics` 各一份 | 只留 `b_metric.py` | 口径必须唯一 | `grep` 验证仅两处调用 |

**b 口径修正的完整实测（50 场景）**

| 算法 | 旧口径 | 新口径 |
|---|---|---|
| greedy | 0.9958 ± 0.0220 | **0.9983 ± 0.0071** |
| ga_iap | 0.4046 ± 0.1281 | **0.8887 ± 0.1487** |

配对效应量从 **−7.32** 降到 **−0.75**；**a、d、destroyed、used 逐位不变** → 证明是纯测量修正，未扰动仿真。

## 5. 关键结论汇总

### 结论 1：指标口径的漂移足以让结论错 5 倍

> 原文档写"复现算法让威胁消除率从 0.996 跌到 0.397"。真实值是 **0.889**。
> 差异来源不是算法，而是**分母随算法行为膨胀 2.52 倍**。

**教训**：口径不统一时，任何"算法优劣"的结论都不成立。

### 结论 2：3n 编制下算法无可比性

| 编制 | 随机解与贪心的分数差 |
|---|---|
| 3.0n | **0.26%**（统计上不可区分） |
| 2.5n | **8.01%**（31 倍） |
| 2.0n | 2.60% |

**原因**：每波敌机在当回合即被歼灭，兵力从未真正绑定。
**处理**：引入三档编制；2.5n 定为"主档"。

### 结论 3：5 个算法在三档下的排名

| 档位 | 算法 | a_kill | b | 综合分 |
|---|---|---|---|---|
| easy 3.0n | greedy | 647.96 | 0.9983 | **1.0000** |
| | cbba_ye | 647.86 | 0.9970 | 0.9996 |
| | ga_iap | 642.60 | 0.8887 | 0.9781 |
| normal 2.5n | ga_iap | **622.80** | 0.6904 | 1.0027 |
| | cbba_ye | 583.44 | 0.8861 | 0.9989 |
| | greedy | 582.94 | 0.8935 | 1.0000 |
| hard 2.0n | ga_iap | **526.52** | 0.5649 | **1.0683** |
| | cbba_ye | 456.28 | 0.6898 | 0.9979 |
| | greedy | 455.94 | 0.6997 | 1.0000 |

**统计**：12 组 Friedman 全部 `p < 1e-21`；`k=4, N=50` 时 `CD = 0.663`。

### 结论 4：**本擂台的区分维度只有"预留系数 α"**（最重要）

三条相互印证的证据：

**① 单轮分配可精确求解，且最优解 = 贪心**
$1-(1-p)^k$ 是凹函数 → 目标按"第几架"展开成槽 → 最大权二分匹配有精确解 → **该解恰等于"按配额填满"的贪心规则**。

**② 配对天花板只有 2.37%**
固定贪心的配额分配，同架数下换最优配对（**忽略机争用的乐观上界**）只多 **2.37%**；关闭距离时 **0.00%**。

**③ 各算法的出动比**

| 算法 | 本轮出动 ÷ 可行容量 |
|---|---|
| greedy / cbba_ye | **1.000** |
| random_feasible | 1.02 |
| **ga_iap** | **0.689** |
| myopic_opt | 2.59 |

**因果验证**：给 greedy 加一个"每轮只打 α 倍"的参数，**α=0.7 就复现了 ga_iap 的全部画像**——a_kill 621.5 vs 622.8、效应量 +2.12 vs +1.99、b 跌幅 −0.205 vs −0.203。

### 结论 5：最优预留比例随兵力收紧单调下降

| 档位 | 最优常数 α | 最优逐波调度 | 歼灭价值 |
|---|---|---|---|
| easy 3.0n | **1.00**（不预留） | 同常数 | 655.10 |
| normal 2.5n | **0.55** | `0.40/0.40/1.00` | 631.87 |
| hard 2.0n | **0.40** | `0.40/0.40/0.55` | 588.27 |

- 逐波调度只是**二阶效应**（+0.7~1.0%）；一阶效应是"α 的量级对不对"。
- **hard 档下，greedy + 三个数（588.3）反超 ga_iap（524.9）12.1%。**
- 原因：ga_iap 的 α≈0.69 是"最小化出动架数"的副产品，**不随档位自适应**。

### 结论 6：灵敏度——哪些参数是杠杆

| 参数 | 影响 | 数据 |
|---|---|---|
| **歼灭阈值** 0.80→0.95 | **强** | ga_iap 综合分 0.9678 → 1.0610 |
| **侦察机占比** 15%→45% | **强** | ga_iap a_kill 优势 +1.50 → +65.03（d 0.19 → 2.00） |
| 杀伤强度 ×0.5→×2 | 弱 | 主项优势 +41±1（d≈2.0） |
| 威胁度加权方式 | 弱 | 熵权/等权/仅价值 差 ≤0.7 分 |
| 威胁排序**完全失效** | 中 | 优势缩水 3 倍（d 1.99 → 0.54） |

**阈值 0.80 与 0.85 的配额表相同（4/2/1），结果逐位一致** → 参数网格应按"配额表"取点，不是按阈值取点。

### 结论 7：文献算法的移植性

复现叶赞改进 CBBA 的完整证据链：

| 原文改进 | 本场景移植结果 |
|---|---|
| 价值函数（风速+海拔代价） | **无法移植**（无风场、无海拔、不建模飞行） |
| 任务包双向构建 + 候选池 | 可实现，但**反而有害**（去掉后 a_kill +0.33） |
| K-means 区域 + 同类奖励 | 可实现，但**几乎无影响**（a_kill 完全不变） |
| **"两者都关"的结果与 greedy 逐位相同** | 印证结论 4 |
